Offline Velocity Estimation Using Savitzky–Golay Smoothing and Kalman Filtering

Signal Processing • Digital Control Context • Robotics Sensing (Encoder Quantization) • Evaluation & Tuning
Controls / Estimation Signal Processing Variable Δt Encoder Noise Evaluation

Overview

This project focused on improving velocity estimates derived from encoder measurements for a precision robotic system. In practice, naive differentiation amplifies quantization noise and sampling irregularities, especially at low speeds. I built an offline pipeline combining Savitzky–Golay smoothing and a Kalman filter (with empirically tuned noise models) to produce more reliable velocity estimates for downstream control and analysis.

My role
  • Designed and implemented the offline estimation pipeline (smoothing + filtering).
  • Characterized measurement noise and built covariance models (including correlated noise).
  • Evaluated error patterns vs. velocity and diagnosed low-speed quantization effects.

Note: Some implementation details and datasets are not shared publicly due to course/lab constraints.

Problem

  • Low-speed quantization: encoder resolution leads to “stair-step” position signals and noisy velocity after differentiation.
  • Irregular sampling: real logs may have variable Δt, which complicates discrete-time filtering assumptions.
  • Noise coupling: measurement channels can be correlated (e.g., position/velocity/acceleration estimates derived from the same signal).

Approach

1) Preprocessing with Savitzky–Golay
  • Applied Savitzky–Golay smoothing to reduce quantization noise while preserving motion features.
  • Computed derivative signals (velocity/acceleration) from the smoothed fit where appropriate.
2) Discrete-time Kalman filter with practical timing
  • Used a state-space formulation suitable for motion signals (position/velocity/acceleration variants depending on configuration).
  • Handled variable sampling intervals by updating the discrete-time model using the measured Δt between samples.
  • Tuned process/measurement noise using empirical statistics from measured vs. reference signals.
3) Empirical noise modeling & tuning
  • Estimated noise distributions and covariance from data residuals.
  • Tested correlated covariance structures to better reflect real sensor/derivation coupling.
  • Performed sensitivity checks to ensure stable filtering behavior across operating speeds.

Results (What improved)

  • Smoother low-speed velocity: reduced spiky differentiation artifacts caused by encoder quantization.
  • Better consistency under variable Δt: filtering remained stable when sampling intervals changed.
  • More interpretable error trends: error-vs-velocity analysis helped diagnose quantization-dominated regimes.

What I learned

  • Why low-speed motion is often the hardest regime for encoder-derived velocity (quantization + timing effects).
  • How noise modeling choices (especially correlated noise) can significantly affect Kalman filter behavior.
  • The importance of evaluation plots (e.g., residuals and error-vs-velocity) for debugging estimation pipelines.
