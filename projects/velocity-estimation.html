Offline Velocity Estimation Using Savitzky–Golay Smoothing and a Kalman Filter with Acceleration Input

Controls / Signal Processing • Variable Δt Discrete-Time Modeling • Encoder Noise • Offline Evaluation
Digital Control Context Signal Processing Kalman Filtering Variable Δt Noise Modeling

Overview

This project improves encoder-derived velocity estimates using an offline pipeline that combines Savitzky–Golay (SG) smoothing with a discrete-time Kalman filter (KF). The main challenge is that quantization and differentiation amplify noise, especially at low velocities. The final estimator treats measured acceleration as an external input to a position–velocity KF and evaluates performance against provided reference signals.

What I did
  • Applied a 5-point quadratic Savitzky–Golay smoother to measured signals to reduce high-frequency noise.
  • Implemented a discrete-time KF with states [position, velocity], using measured acceleration as an input.
  • Handled non-constant sampling by updating the state transition each step using measured Δt.
  • Estimated empirical noise statistics and used correlated measurement covariance for tuning.
  • Evaluated filtered estimates vs. reference position/velocity and analyzed error behavior.

Some code/data are not shared publicly due to course/lab constraints, but the full technical report is available below.

Problem

  • Quantization + differentiation: encoder position is “stair-stepped,” and taking derivatives amplifies noise at low speed.
  • Variable sampling: the dataset time column is real time in seconds, but Δt varies slightly from sample to sample.
  • Robustness: acceleration can change abruptly, which can break constant-acceleration model assumptions.

Dataset & Evaluation Setup

The dataset provides measured signals (mpos, mvel, maccel) and reference signals (rpos, rvel, raccel). Reference signals are used only for offline evaluation, not for filtering. Measurement errors are defined as (measured − reference), and estimation errors use (KF estimate − reference).

Method

1) Savitzky–Golay smoothing (5-point quadratic)

A symmetric 5-sample quadratic SG smoother is applied independently to the measured position, velocity, and acceleration. The convolution kernel is: 

c = (1/35) * [-3, 12, 17, 12, -3]

(Derived from a local least-squares quadratic fit over i ∈ {-2,-1,0,1,2}.)

2) Kalman filter with acceleration as external input

State: xₖ = [pₖ, vₖ]ᵀ. The model updates at each step using the measured sampling interval Δtₖ. 

Fₖ = [[1, Δtₖ],
      [0, 1 ]]

Gₖ = [[0.5 * Δtₖ^2],
      [      Δtₖ ]]

xₖ₊₁ = Fₖ xₖ + Gₖ aₖ + wₖ
zₖ   = [mpos(tₖ), mvel(tₖ)]ᵀ = H xₖ + vₖ,  H = I

Key design choice: measured acceleration aₖ is treated as an input rather than an estimated state, improving robustness to abrupt changes.

3) Empirical noise modeling (correlated measurement covariance)

Noise statistics are estimated from measured–reference differences. A 3×3 covariance is computed, and the KF uses the position–velocity block as R. Acceleration variance contributes to process noise through Qₖ = Gₖ σ²ₐ,eff Gₖᵀ. 

R (position–velocity block) =
[[   1.8556,   -9.8784],
 [  -9.8784, 1662.6606]]

σ²_a (from empirical covariance) = 987265.9388

Results Summary

  • Position: KF estimate is smoother than measurement while remaining aligned with reference.
  • Velocity: KF substantially reduces noise and staircase artifacts in measured velocity, especially around low-speed and reversals.
  • Errors: velocity error variance decreases significantly after filtering; remaining lag appears during aggressive transitions (tuning trade-off).

Key Design Insight

Why “acceleration as input” (not a 3-state constant-accel model)

An initial constant-acceleration state model (p, v, a) performed worse when measured acceleration changed abruptly. Treating acceleration as an external input removed the assumption that acceleration evolves smoothly under a model, improving robustness and velocity estimation performance.

Next Steps

  • Apply SG only to position, then compute velocity/acceleration analytically from the fitted polynomial for derivative consistency.
  • Improve noise modeling via analytical noise propagation (position → velocity/acceleration) to better explain correlations.
  • Validate on representative dVRK motion ranges and explore regime-dependent tuning.
