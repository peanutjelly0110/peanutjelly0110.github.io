Brain CT Hemorrhage Detection Ongoing

Computer Vision • Medical Imaging • Deep Learning

Overview

This project aims to develop a computer vision pipeline for automated detection of intracranial hemorrhage from non-contrast head CT scans. Rapid and reliable identification of hemorrhage is critical for emergency diagnosis and treatment planning.

The primary objective is binary classification (hemorrhagic vs. normal CT slices), with longer-term goals of supporting localization and clinically meaningful outputs such as anatomical region and estimated bleed volume.

Dataset

  • Kaggle Brain CT Hemorrhage Dataset
  • 6,772 CT slices (2,667 hemorrhagic / 4,105 normal)
  • 512 × 512 resolution grayscale images
  • Supervised binary classification task

Candidate Approaches

We are currently evaluating several candidate model families. The final architecture will be selected based on validation performance, robustness, and computational constraints.

Baseline CNN
  • Compact convolutional network trained from scratch.
  • Establish preprocessing, augmentation, and evaluation protocol.
  • Provide a performance reference point for deeper models.
Transfer Learning (e.g., ResNet / DenseNet)
  • Evaluate pretrained backbones adapted to CT slice classification.
  • Compare performance vs. model complexity and training stability.
Future Extensions
  • Localization via saliency maps or Grad-CAM.
  • Segmentation-based methods for anatomical region identification.
  • Estimation of hemorrhage volume for clinical relevance.

Current Status

  • Literature review and dataset exploration completed.
  • Data preprocessing and train/validation/test split under development.
  • Baseline experiments beginning; model selection is ongoing.

Tools & Resources

  • Python
  • PyTorch / TensorFlow (architecture selection in progress)
  • Google Colab (GPU acceleration)

Project Motivation

While acute hemorrhages are often visually apparent, subacute and subtle cases can be difficult to detect due to low contrast between isodense blood and surrounding brain tissue. This project explores how deep learning methods can assist clinicians by standardizing detection and reducing diagnostic delay.
