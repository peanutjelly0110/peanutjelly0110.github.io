Brain CT Hemorrhage Detection Ongoing

Computer Vision • Medical Imaging • Deep Learning

Overview

This project focuses on developing a computer vision pipeline to automatically detect and localize intracranial hemorrhage from non-contrast head CT scans. Rapid identification of hemorrhage type and location is critical for emergency diagnosis and treatment planning.

The goal is to build a model capable of classifying hemorrhagic vs. normal CT slices, with future extensions toward anatomical localization and volume estimation.

Dataset

  • Kaggle Brain CT Hemorrhage Dataset
  • 6,772 CT slices (2,667 hemorrhagic / 4,105 normal)
  • 512 × 512 grayscale images
  • Binary classification (Normal vs Hemorrhagic)

Technical Approach

Convolutional Neural Networks (CNN)
  • Baseline CNN architecture trained from scratch.
  • Feature extraction of hyperdense hemorrhagic regions.
ResNet
  • Exploring residual connections to improve gradient flow.
  • Transfer learning for improved generalization.
DenseNet
  • Dense connectivity for improved feature reuse.
  • Evaluating parameter efficiency vs. performance.

Current Progress

  • Dataset exploration and preprocessing pipeline established.
  • Baseline CNN architecture under development.
  • Initial training experiments using Google Colab GPU.

Tools & Resources

  • Python
  • PyTorch / TensorFlow (depending on final selection)
  • Google Colab (GPU acceleration)

Next Steps

  • Hyperparameter tuning and performance evaluation.
  • Model comparison (CNN vs ResNet vs DenseNet).
  • Expand from classification toward localization and volume estimation.
