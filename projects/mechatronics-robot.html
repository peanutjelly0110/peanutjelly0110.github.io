Autonomous Wall-Following & Ball-Sorting Robot

Embedded C (C2000) • Raspberry Pi • PID Control • Camera Calibration • Autonomous Behavior
Mechatronics Embedded Systems PID Control Sensor Integration State Machines

Project Overview

As part of SE423 – Introduction to Mechatronics at UIUC, our team built an autonomous mobile robot capable of navigating a maze while hugging the right wall. The robot detected colored golf balls (pink and purple), collected them, stored them in separate compartments, and executed a final sorting and stop routine at a designated location.

The system used a dual-board architecture:

  • TI LaunchXL-F28379D (C2000 MCU) for real-time motor control and feedback loops
  • Raspberry Pi for camera interfacing, color calibration, and classification
---

System Architecture

Real-Time Control (C2000 – Embedded C)
  • PWM motor control using hardware timers
  • Encoder-based velocity feedback
  • PID-based speed and steering control
  • Interrupt-driven control loops

The C2000 handled all time-critical tasks to ensure deterministic motor behavior.

Perception & Camera Processing (Raspberry Pi)
  • Camera calibration for color recognition
  • Color classification (pink vs. purple golf balls)
  • Triggered pickup behavior based on classification

The Raspberry Pi was used because camera processing and calibration are better suited for a Linux-based system than a real-time MCU.

---

Control Strategy

Right-Wall Following
  • Maintained desired wall distance using distance sensor feedback
  • Steering corrections applied through PID control
  • Speed regulation via encoder-based feedback

A key engineering challenge was tuning PID gains to balance responsiveness (tight corners) with stability (avoiding oscillations or wheel slip).

---

Autonomous Behavior (State Machine)

The robot behavior was implemented as a finite-state machine: 

Wall-Follow → Detect Ball → Approach & Pickup → Store (Left/Right)
        ↘___________________________________________↗
                   Final Sorting → Stop

Each state was tested independently before integrating the full autonomous sequence.

---

Localization & Monitoring

Motion Capture Tracking

Reflective marker balls mounted on the robot allowed the lab motion-capture system to track its position in the global coordinate frame. This was used for monitoring and evaluation, not for low-level control.

Course material also introduced Kalman filtering to combine dead-reckoning and motion-capture data for improved pose estimation in robotics systems.

---

What I Learned

  • How to partition a robotics system between real-time control and high-level processing
  • Practical PID tuning under real-world mechanical constraints
  • How sensor noise and timing affect closed-loop performance
  • How to debug embedded C systems using interrupts and hardware registers
  • How to integrate perception, control, and behavior into a complete autonomous robot
---

Key Takeaway

This project strengthened my ability to design, implement, and debug full-stack robotic systems — from low-level embedded motor control to high-level perception and autonomous decision logic.
