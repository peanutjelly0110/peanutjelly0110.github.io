Offline Velocity Estimation Using Savitzky–Golay Smoothing and Kalman Filtering Completed

Developed an offline estimation pipeline to improve encoder-derived velocity measurements under variable sampling intervals. Implemented a discrete-time Kalman filter with acceleration treated as an external input and tuned correlated noise covariances using empirical data.

Reduced low-speed quantization artifacts and improved velocity consistency compared to raw differentiated measurements.

Autonomous Wall-Following & Ball-Sorting Robot (TI C2000 + Raspberry Pi) Completed

Designed and implemented an autonomous maze robot using a dual-board architecture: a TI LaunchXL-F28379D (C2000) MCU for real-time motor control and a Raspberry Pi for camera interfacing and color-based object detection.

Implemented right-wall following using PID-based speed and steering control with encoder feedback. Integrated camera calibration and color classification (pink/purple golf balls) to trigger pickup and sorting behaviors before navigating to a final stop location.
